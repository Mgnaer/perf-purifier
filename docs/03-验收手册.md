## 3. 安全验收（红线，阶段 1 + 阶段 2 默认关闭状态）

- [ ] 默认配置下（四个 stage2 开关均为 false），界面中不存在可用的“结束进程 / 删除 / 建立硬链接”动作按钮，或按钮为禁用状态并有配置提示；
- [ ] 阶段 2 动作只出现在对应页面（结束进程=进程血缘页、删除 Temp=临时占用页、硬链接=重复文件页），不存在全局“一键清理/一键优化”入口；
- [ ] 开启开关后，任何动作都必须：勾选目标 + 二次确认（结束进程需输入确认词）；取消不产生任何动作；
- [ ] 删除只调用回收站，回收站失败时不回退为永久删除；
- [ ] 硬链接仅同卷 NTFS，执行前重算哈希；不存在跨卷建链接路径；
- [ ] 结束进程不提供强制结束升级；PID 0/4、自身/祖先、黑名单进程被拒绝；
- [ ] 每个动作写入 `operations.jsonl`（header 先写、item 逐项写；审计失败即中止）；
- [ ] 导出文件中命令行密码/令牌默认被 `***` 遮蔽；
- [ ] 网络需核实判定只基于“公网 + 非受信路径 + 非有效签名”，不出现“病毒/恶意”结论；
- [ ] PID 0 连接标注为“内核/系统连接”，未被归因为某个进程；
- [ ] HTML 报告对 `<script>` 等文件名内容做了转义（`test_html_export` / `test_file_exporters` 已锁定）；
- [ ] junction/符号链接/云占位文件被跳过；重复扫描不会进入 `$Recycle.Bin`；
- [ ] `run.log` 存在且无异常堆栈；断网运行正常；未写注册表/启动项。

## 4. 已知告警与解释

| 现象 | 原因 | 处理 |
|---|---|---|
| `QFontDatabase: Cannot find font directory ...` | 无头（offscreen）模式缺字体目录，仅冒烟脚本出现 | 不影响真实窗口；可忽略 |
| 完整度显示“部分” | 非管理员无法读取提升进程字段 | 管理员运行可改善 |
| 大量进程显示“信息”级标记 | R11：字段不可读（权限不足），权重 2 | 正常；KPI 只统计“关注及以上” |
| `System32` 文件显示“目录签名或未知” | 系统文件多为 catalog 签名，策略上不做“无签名”结论 | 预期行为 |
| 网络“需人工核实 0” | 本机公网连接均来自受信路径/有效签名进程（其余为 PID 0 内核连接） | 正常；换机器可能出现需核实项 |
| 临时占用“疑似被占用 11” | 探测时文件被其它进程持有（缓存/更新器） | 只读探测结果，不代表可删除 |
| 重复文件“可回收 0” | 该组文件互为硬链接，删除任一副本都不释放空间 | 预期行为；UI 有明确说明 |
| 哈希缓存不可用 | SQLite 文件被占用/损坏时自动降级 | 扫描继续，提示 `cache_unavailable`；可删除 `%LOCALAPPDATA%\PerfPurifier\file_hash_cache.sqlite3` 重建 |
| 并发显示 1（或 2）而非 4 | HDD 为保护随机寻道强制串行；虚拟盘/检测失败保守 2 并发 | 预期行为；可用 `file_scan_hash_workers` 覆盖 |
| 结果中缺少某目录 | 命中排除规则、预算上限或权限不足 | 查看“扫描提示”（`walk_excluded` / `walk_truncated` / `walk_unreadable`） |
| 扫描大目录较慢 | 单线程/低并发顺序读取（HDD 自适应） | 可随时取消；使用哈希缓存加速二次扫描 |
| 文件列表没有某目录 | 命中预算上限（默认 30 万文件/120s）或权限不足 | 查看“扫描提示”与数据完整度，可调整 config |

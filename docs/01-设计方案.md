# 设计方案（阶段 1A / 1B）

## 1. 定位

本地只读系统检查工具：**扫描 → 可视化 → 导出**。不可逆动作（结束进程、删除文件、硬链接）
一律后置到阶段 2，且必须经过预览、二次确认、白名单与操作日志。程序不联网。

## 2. 功能边界

### 模块 A（进程/网络/临时占用）

| 能力 | 阶段 | 说明 |
|---|---|---|
| 进程快照 9 字段 | 1A ✅ | 逐字段容错，缺失记录在 `access_errors` |
| 进程树 / 根 / 孤儿 / PID 复用 | 1A ✅ | 纯函数 `build_tree`，可单测 |
| 启发式规则 R01–R11 | 1A ✅ | 规则 ID + 证据，不输出“恶意”结论 |
| 搜索 / 风险筛选 / 详情 | 1A ✅ | 搜索命中保留祖先路径 |
| CSV / JSON 导出 | 1A ✅ | CSV 带 BOM；命令行默认脱敏 |
| 数字签名（WinVerifyTrust） | 1B ✅ | 只校验非受信路径 exe；禁止在线吊销查询；去重缓存 |
| 网络连接（PID 关联/分类/需核实） | 1B ✅ | 失败时降级为逐进程读取并标注完整度 |
| 临时占用（聚合/占用探测） | 1B ✅ | 有文件数/时间预算；只读探测；不跟随 reparse |
| HTML 自包含报告 | 1B ✅ | 内联 CSS、无外链、动态内容全部转义 |

### 模块 B（重复/大文件）—— 阶段 1C ✅

安全遍历（跳过 reparse point / 系统目录 / 云占位，文件数+时间预算）→ 大小分桶 →
4KB 快速指纹 → SHA-256 全量 → 分组（硬链接感知可回收空间）→ 双栏对比 → Top-N 大文件 →
CSV/JSON/HTML 导出。**不提供删除/硬链接动作**（留到阶段 2）。

## 4. 数据模型（`core/models.py`，schema 1.1）

```python
ProcessInfo(pid, ppid, name, exe, cmdline, username, create_time,
            status, rss, vms, sig_status, sig_publisher, access_errors)

ProcessNode(info, parent_pid, children, depth,
            flags: list[RiskFlag], score, risk, orphaned, parent_pid_reused)

RiskFlag(rule_id, severity, weight, title, evidence)
ProcessTree(nodes, roots, orphans, cycles, warnings, completeness, ...)

Endpoint(address, port)
ConnectionInfo(pid, family, protocol, status, laddr, raddr, remote_class,
               is_listen, is_kernel, process_*, needs_review, review_reason, note)
NetworkScanResult(connections, completeness, elapsed_ms, warnings)

TempRoot(path, kind, exists)
TempEntry(root, path, is_dir, size, file_count, mtime, occupancy, occupancy_detail)
TempScanResult(roots, entries, total_size/files, probed/candidates,
               skipped_reparse, unreadable, completeness, probe_note, warnings)

ProcessScanResult(tree, started_at, finished_at, is_admin, connections, temp)
```

约定：`ProcessInfo` 不可变快照；树/评分/导出只读不写回；风险等级只用于排序筛选。

## 5. 进程树算法

1. `ppid < 0`（不可读）或 `ppid == pid`（自引用）→ 根；
2. 父不在快照 → 根；`ppid != 0` 时同时标记 `orphaned`；
3. **PID 复用**：父 `create_time` 晚于子进程 0.5s 以上 → 判定父已退出、PID 被复用，
   子进程建为根并标 `parent_pid_reused`；
4. 环/残留节点 → 断开父子链、提升为根并记录 `cycles` 警告，绝不死循环；
5. DFS 计算 `depth`，子节点按显示名排序，保证展示稳定。

## 6. 启发式规则（评分仅用于排序）

| ID | 判据 | 级别 | 权重 |
|---|---|---|---|
| R01 | exe 位于 %TEMP%/Downloads 等用户可写目录 | 可疑 | 12 |
| R02 | 无数字签名（非受信路径） | 关注 | 4 |
| R02B | 签名无效/被篡改 | 可疑 | 15 |
| R02C | 已签名但证书链不受信任/过期 | 关注 | 6 |
| R03 | 父进程已退出 / 父 PID 被复用（受信路径与常见正常进程豁免） | 关注 | 6 |
| R04 | 系统进程名来自非预期路径（伪装的 svchost/lsass 等） | 高风险 | 30 |
| R05 | 关键系统进程父进程异常 | 高风险 | 25 |
| R06 | 命令行 LOLBin 特征（系统二进制+受信父进程时降级为关注） | 高风险 | 25 |
| R07 | Office/PDF/IM 进程派生 cmd/powershell/wscript 等 | 高风险 | 25 |
| R07B | 浏览器派生命令行类子进程（可能正常更新，需核实） | 关注 | 8 |
| R09 | 从 UNC 网络路径运行 | 高风险 | 20 |
| R10 | name 与 exe basename 不一致（容忍 Windows 15 字符截断） | 关注 | 5 |
| R11 | 字段不可读（权限不足） | 信息 | 2 |

等级 = `max(总分档位, 单条规则最高级别)`；总分：0–9 信息 / 10–24 关注 / 25–49 可疑 / ≥50 高风险。

## 7. 网络连接判定（1B）

- 采集：`psutil.net_connections(kind='inet')`；`AccessDenied`/异常 → 逐进程降级并标注 PARTIAL；
- 地址分类（纯函数）：回环 / 内网 / 运营商 NAT(100.64/10) / 链路本地 / 组播 / 保留 / 公网 / 未知；
- **需人工核实** = 公网远端 且（进程不在受信路径且签名非 VALID，或无法关联用户进程）；
- **PID 0 是内核/系统连接**，不归因到 System Idle Process，单独标注 `is_kernel`，不计入需核实；
- 已签名 VALID 的用户目录程序、受信路径（Program Files/Windows）程序不标记；
- 离线不做 CDN/云厂商识别，不反向 DNS（避免阻塞/联网）；LISTEN 单独统计。

## 8. 数字签名策略（1B）

- ctypes 调用 `WinVerifyTrust`（`WTD_UI_NONE` + `WTD_CACHE_ONLY_URL_RETRIEVAL` + `WTD_SAFER_FLAG`），
  **禁止在线吊销查询**，不联网、不弹窗；
- 受信路径（Windows/Program Files/ProgramData）→ `CATALOG_OR_UNKNOWN`，不做“无签名”结论
  （系统文件多为 catalog 签名，直接校验会误报）；
- 非受信路径按 exe 去重校验，结果按 `(路径, size, mtime)` 缓存，受 250 文件/8s 预算约束；
- HRESULT 映射：0 → VALID；NOSIGNATURE/SUBJECT_FORM_UNKNOWN → UNSIGNED；
  BAD_DIGEST/EXPLICIT_DISTRUST/REVOKED → INVALID；证书链/过期类 → SIGNED_UNTRUSTED；
  未知 HRESULT → CATALOG_OR_UNKNOWN（不做结论性映射）。

## 9. 临时占用扫描（1B）

- 根：`%TEMP%`、`%TMP%`、`%SystemRoot%\Temp`、`%LOCALAPPDATA%\Temp` +
  已知缓存（INetCache/Edge/Chrome/pip/D3D/NVIDIA/CrashDumps），按规范化路径去重；
- 聚合：根下一层条目（目录为递归聚合的 文件数/总大小/最新 mtime）；
- 不跟随符号链接/junction（`GetFileAttributesW & REPARSE_POINT`），记录跳过数量；
- 预算：默认 200k 文件 / 8s，超限标注“结果可能不完整”，随时可取消；
- 占用探测：`CreateFileW(GENERIC_READ, share=0)` 只读探测；只探测最大的 ≤300 个 ≥1MB 文件，
  2s 预算；`ERROR_SHARING_VIOLATION/LOCK_VIOLATION → 可能被占用`，`ACCESS_DENIED → 无权限`；
  **未探测≠未占用**，杀软干扰可能误判，UI 明示。

## 10. 数据完整度

- `FULL`：全部阶段数据可读；
- `PARTIAL`：存在不可读字段/跳过进程/Temp 预算触顶/占用探测不完整（非管理员常见）；
- `DEGRADED`：进程枚举、网络采集或临时目录根全部失败等会话级问题。

只读红线：不渲染任何结束/删除/链接控件；UI 文案不出现“清理/优化/加速”承诺。

## 11. 线程 / 取消 / 进度 / 日志

- `ScanJob(QObject)` 移入 `QThread`；信号：`stage_changed / progress / warning / finished / failed / cancelled`；
- 全部阶段共享一个 `CancelToken`：进程级、连接级、每 200 个文件/1MB 块检查；取消后不再发起新 I/O；
- 进度 10Hz 合流；页面与主窗口状态栏同时显示阶段/百分比；
- 窗口关闭先取消并 `wait(3000ms)`，不使用 `terminate()`；
- 日志：`run.log`（轮转）+ `operations.jsonl`（阶段 2 动作审计契约）。

## 13. 模块 B：重复文件/大文件（1C ✅）

**流水线**：遍历（`os.scandir` 递归，跳过 REPARSE/系统目录/云占位/排除规则；文件数 30 万、时间 120s 预算）
→ 过滤（最小大小 / 扩展名 / 修改时间）→ 大小分桶 → 前 4KB SHA-256 快速指纹
→ 指纹相同者做全文件 SHA-256（可并发）→ 按 `(大小, 全量哈希)` 分组
→ 硬链接识别 → 可回收估算 → 建议保留。

**关键细节**：

- **硬链接识别**：Windows 上 `DirEntry.stat()` 的 `st_dev/st_ino` 恒为 0，因此只对进入重复候选的
  文件用 `os.stat()` 补全 `(卷序列号, 文件索引)`；同一 identity 的路径指向同一份数据，
  `可回收 = 单文件大小 × (独立 inode 数 − 1)`，全组同 inode 时标"已互为硬链接（删除无收益）"；
  无法读取 inode 时按"相互独立"保守估算并给出警告；
- **稳定性校验**：读取前后各 stat 一次，大小/mtime 变化则标记"扫描期间变动"并剔除；
- **禁止误判**：4KB 指纹只用于预筛，最终以全文件 SHA-256 为准（单测覆盖"前 4KB 相同、尾部不同"）；
- **长路径/云占位**：普通打开失败用 `\\?\` 重试；云占位文件按属性跳过（避免触发 OneDrive 下载）。

**1C 增强**：

- **排除规则**：名称/通配符（如 `node_modules`、`*.tmp`）或绝对路径前缀；命中目录不进入、命中文件不计入；
  排除数量在扫描提示与报告里可见；
- **类型/时间过滤**：按扩展名预设（图片/视频/文档/音频/压缩包）与修改时间（7/30/90/365 天）筛选参与去重的文件；
- **并行哈希（HDD 自适应）**：`IOCTL_STORAGE_QUERY_PROPERTY(SeekPenalty)` 探测介质：
  HDD → 1 并发（避免随机寻道恶化），SSD → 最多 4 并发，探测失败 → 保守 2 并发；
  显式 `file_scan_hash_workers` 可覆盖；分块提交（512 个/批）控制内存；
- **SQLite 哈希缓存**：`%LOCALAPPDATA%\PerfPurifier\file_hash_cache.sqlite3`，按
  `(路径, 大小, 修改时间)` 复用 SHA-256；大小/mtime 变化自动重算；默认 30 天 TTL；
  数据库任何异常自动降级为无缓存，不影响扫描；
- **建议保留**：启发式规则（路径层级最浅 → 修改时间更早 → 路径字典序），组内把建议项排第一，
  UI/CSV/JSON/HTML 均标注"建议保留"；**仅建议，不执行任何操作**。

**只读边界**：无删除/硬链接入口；删除与硬链接属于阶段 2（预览 + 二次确认 + 黑名单 + 审计日志）。

**实测**（本机合成样本 8 个文件，含硬链接与 4KB 前缀干扰项）：排除规则跳过 1 项；
3 组重复 / 6 个重复文件 / 可回收 8006 字节；硬链接组可回收 0；干扰项未被误判；
介质探测为 hdd → 并发 1；首次 94 ms，二次（缓存命中 7）27 ms。

## 14. 阶段计划

- **1A ✅**：进程血缘只读扫描 + CSV/JSON；
- **1B ✅**：签名校验、网络连接页、临时占用页、HTML 报告；
- **1C ✅**：模块 B 重复文件/大文件/双栏对比（只读）；
- **阶段 2**：结束进程 / 回收站删除 / 硬链接（预览 token + 二次确认 + 动作黑名单 + 审计日志 + 跨盘降级）；
- **阶段 3**：PyInstaller 打包、管理员重启入口、单实例；
- **阶段 4**：SQLite 结果缓存、严格逐字节比对、离线 ASN/CDN 名单、自启动项只读视图。

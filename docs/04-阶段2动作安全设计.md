# 阶段 2 动作安全设计（评审通过版）

> 状态：S1–S12 已确认（"全部按推荐"）。里程碑 2A（动作安全框架）已实现并通过测试。
> 原则：**无预览不执行、删除只走回收站、审计失败不静默继续、默认全部关闭。**

## 1. 范围（S1）

| 动作 | 说明 | 默认 |
|---|---|---|
| 2C 删除 Temp 文件 | `send2trash` 回收站，仅文件（S4） | 关闭 |
| 2D 硬链接去重 | 同卷 NTFS、内容哈希复验、原子替换 | 关闭 |
| 2B 结束进程 | Windows 上即 TerminateProcess（无优雅退出） | 关闭 |

不做：永久删除回退、自动提权、全选删除、清理内存、静默执行。
新增依赖：`send2trash>=1.8`（已安装并写入 `requirements.txt`）。

## 2. 动作闸门（不变量）

```
扫描结果快照 → 勾选目标 → 生成预览 token（内存、一次性、120s 过期、绑定策略版本）
→ 纯函数策略检查 → 二次确认（清单 + 后果 + 勾选/输入确认词）
→ ActionJob(QThread) 逐项执行（执行前重验身份；失败不中断、不回退）
→ operations.jsonl：header 先写、item 逐项写；审计失败立即中止
```

硬性不变量：
1. 没有扫描结果（CompletenessVerdict）不允许动作；
2. `limited` 完整度禁止一切动作（S3），只能重扫后再试；
3. 主开关 + 分动作开关均默认关闭（S2）；
4. 同一时刻只允许一个动作任务，动作期间禁止扫描；
5. token 过期/策略版本变化/动作不一致 → 整批拒绝（任何动作前）；
6. 目标身份（路径 stat / 进程 pid+create_time+exe / 文件 dev+ino）在执行前重验，不匹配即拒绝该项；
7. **删除只调用 `send2trash`**，失败上报，绝不回退 `os.remove`；
8. 审计 header 写失败 → 不执行任何目标；item 写失败 → 中止剩余目标并上报；
9. 失败不中断其它项（逐项记录），不自动重试。

## 3. 预览 token

- 字段：`token_id / action / created_at / expires_at / policy_version / item_count / total_bytes / target_signature`；
- 只存在内存（不落盘防篡改），一次性使用；创建与校验均为纯函数（时间由调用方注入）；
- `policy_version` 当前为 `2a.1`，策略变更后旧 token 自动失效；
- UI 必须在执行前展示"目标数/总大小/后果/不可撤销性"。

## 4. 逐项安全规则

### 4.1 2C 删除 Temp（S4：仅文件）

拒绝：目录、路径为空、重复路径、已不存在、不在声明的扫描根内、扫描根不在允许列表、
reparse point、`occupancy=locked`、`occupancy=no_access`。
警告（不阻断）：`not_probed`（未探测 ≠ 未占用）。
批量上限：默认 200 项 / 5 GiB（S6）。

### 4.2 2D 硬链接去重（默认关闭，S7）

拒绝：路径为空/相同、重复冗余路径、文件已不存在、缺少内容哈希、身份未知（inode 不可用）、
两路径已同 inode、组内已存在硬链接（`is_mutual_hardlink`/`is_fully_hardlinked`）、
跨卷、非 NTFS、执行前重算哈希不一致、大小不一致。
允许：同卷 NTFS + 内容哈希一致 + 组内无硬链接；**安全替换算法**：
`os.link(canonical → 临时名)` → `os.replace(临时名 → redundant)` → 校验 `(dev,ino)` 与 `nlink`，
失败清理临时文件；绝不跨卷。
必须告知（事实限制）：替换后冗余路径的 **mtime/ACL 会变为保留文件的**；无自动回滚，只能手动复制恢复。

### 4.3 2B 结束进程（默认关闭，S5）

拒绝：PID 0/4、`NEVER_TERMINATE_NAMES` 命中、本程序自身及祖先链、身份与快照不匹配
（已退出/PID 复用）、身份信息不完整（create_time/name 缺失）、重复 PID。
警告：该进程存在需人工核实的公网连接（P0 `is_needs_review` 结果及原因）。
确认方式：勾选 + **输入确认词「结束进程」**；不提供"强制结束"升级（MVP 不追加升级手段）。
Windows 语义：`psutil.terminate()` 等价 TerminateProcess，未保存数据会丢失，确认框必须明示。
批量上限：默认 20 个（S6）。

## 5. 二次确认交互（S5）

- 默认「确认执行」不可点击，必须勾选"我已了解后果"；高风险动作额外要求输入确认词；
- 目标清单只读展示；取消按钮默认聚焦；对话框关闭不产生任何副作用；
- 文案必须包含"可恢复/不可撤销"结论与失败处理方式（例如"回收站不可用会失败，不会永久删除"）。

## 6. 审计日志（S9，`operations.jsonl`）

- **header**（执行前）：`record_type/session_id/token_id/action/policy_version/verdict_level/verdict_codes/is_admin/item_count/total_bytes/app_version/dry_run`；
- **item**（逐项）：`record_type/session_id/action/target/identity/result/error_code/detail/duration_ms`；
- 敏感信息：命令行只用 `redact_cmdline_text` 结果，不记录文件内容；
- append-only；写失败抛 `AuditWriteError` 并中止；暂不轮转（后续可加 10MB 轮转）。

## 7. 失败矩阵与回滚期望

| 情形 | 处理 | 回滚 |
|---|---|---|
| 权限不足 | 该项 failed/permission_denied | 无（文件未动） |
| 文件被占用/回收站不可用 | failed/trash_unavailable，不回退永久删除 | 无 |
| 预览后路径/进程变化 | 该项 refused/stale（token 级问题整批拒绝） | 无 |
| 跨卷/非 NTFS/哈希不一致 | refused/cross_volume|non_ntfs|content_changed | 无（替换前拒绝） |
| 进程已退出/PID 复用/受保护 | skipped 或 refused/protected|identity_changed | 无 |
| 审计写失败 | 立即中止并提示 | 已执行项不可自动回滚 |
| 回收站删除 | 用户可在回收站手动还原 | 手动 |
| 硬链接替换 | 手动复制可恢复为独立文件 | 手动 |
